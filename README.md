# Forja

App personal de gym (PWA): registro de series, progreso, cuerpo, comida, guía de ejercicios y coach sin internet. Los datos de cada usuario se guardan solo en su propio teléfono.

- Fotos de ejercicios: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (dominio público).
- Videos: generados con IA (Wan 2.2) a partir de esas fotos.
- Letras: Instrument Serif y Bricolage Grotesque (SIL Open Font License).
